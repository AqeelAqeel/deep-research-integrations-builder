First, create a Notion integration:
Go to https://www.notion.so/my-integrations
Click "New integration"
Give it a name (e.g., "Deep Research Integration")
Copy the "Internal Integration Token"
Then, in Notion:
Go to the page where you want the reports to be created
Click the "..." menu in the top right
Click "Add connections"
Select your integration from the list
Get the page ID:
The page ID is in the URL when you're viewing the page
It's the long string after the last "/" and before any "?"
For example: in https://www.notion.so/myworkspace/83jf7... the ID would be 83jf7...
